# HD pack additions

Textures the built-in HD pack (dogerki's "Scooby Doo: Night Of 100 Frights! HD Texture Pack", downloaded by
`tools/stage-userdata.ps1`) doesn't have. They are copied on top of it into `texture_pack/ScoobyHD`.

- `ScoobyHD/tex1_64x64_*_14.png` (16 files): the Creeper window animation frames in the hub (`h001`), drawn in the HD
  pack's style by a script from the game's own frames (issue #24). The dormer roof and sill sample these textures too.
